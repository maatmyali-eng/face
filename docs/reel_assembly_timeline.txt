SEGMENT DETAIL
──────────────

SEG 0 — HOOK (0–5s)
  Visual:    text_card ("bold_white" style) with reel_script.hook text
  Overlay:   Large bold text centered, slight shadow, 1s fade-in
  Voice:     TTS reads hook text (+10% speed for energy)
  Animation: fade_in
  Purpose:   Stop-scroll moment — must grab attention in first 2 seconds

SEG 1–N — BODY SEGMENTS (variable duration, 5s–20s each)
  Visual:    generated_image OR stock_video (per segment visual_type field)
             → generated_image: from image_prompt via Pollinations/HF
             → stock_video: yt-dlp search via stock_video_search_query
  Overlay:   Text overlay on image (if text_overlay_space != null)
  Voice:     TTS reads voiceover_text per segment (tts_voice from plan)
  Animation: zoom_in | fade_in | pan_left | pan_right (from segment plan)
  Grade:     warm | cold | neutral | dramatic (from segment color_grade)

FINAL SEG — CTA (last 5s)
  Visual:    text_card with CTA text (e.g. "Follow for more travel tips!")
  Overlay:   CTA text + follow button emoji
  Voice:     TTS reads CTA text
  Animation: fade_in, fade_out at end
