CRITICAL LIMITS TO WATCH
──────────────────────────────────────────────────────────────────────────────────

⚠️  GitHub Actions minutes
    Running reels every day = ~2,970 min/month vs 2,000 min free limit.
    FIX: Set reels_per_week: 2 or 3 in config.yml.
    With 3 reels/week → ~1,395 min/month (safe margin).

⚠️  Gemini daily quota (1,500 req/day)
    Resets at midnight Pacific time. On exhaustion, FACE logs
    GeminiQuotaExhaustedError and skips gracefully — no data corruption.
    Next pipeline run at quota reset continues normally.

⚠️  Facebook token expiry (~60 days)
    Cannot be automated — requires your manual refresh.
    FACE creates a GitHub Issue when it detects expiry (error code 190).
    This is the only ongoing human touchpoint in the entire system.

✅  Everything else is either unlimited, extremely conservatively used,
    or auto-managed by FACE's built-in rate limiting and caching.
