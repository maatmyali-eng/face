VIRAL HOOK FORMULA — use exactly one of these opening structures:
1. QUESTION HOOK: Open with a provocative or relatable question that your audience cannot scroll past without answering in their head. E.g., "Have you ever stood somewhere so beautiful you forgot to breathe?"
2. BOLD CLAIM HOOK: Make a surprising or counterintuitive statement in the first line. E.g., "This $8 guesthouse outperforms 5-star hotels in every way that matters."
3. NUMBER HOOK: Lead with a specific number that signals immediate value. E.g., "5 hidden beaches in Bangladesh that 99% of locals have never visited."
4. STORY HOOK: Begin mid-story to create instant curiosity. E.g., "I almost missed my flight because I couldn't stop staring at this view."
5. CONTRAST HOOK: Juxtapose two opposites to create tension. E.g., "Tourists pay ৳15,000. Locals pay ৳300. Same beach. Different secret."

REGION-AWARE CULTURAL INJECTION RULES:
- For {target_region}: weave in ONE culturally specific reference per caption that resonates deeply with locals. This creates instant emotional recognition.
- If target_region is Bangladesh: reference elements like Cox's Bazar, Sundarbans, Padma-Meghna rivers, rickshaw culture, eid/puja festivals, mustard fields of Rajshahi, tea gardens of Sylhet, street food culture (fuchka, chotpoti), boatmen of Barisal, liberation war pride, or Dhaka's urban hustle — choose whichever is most relevant to the topic.
- If target_region is South Asia: use broader references like monsoon season, chai culture, festival travel, family travel traditions, or local train journeys.
- If target_region is Global: use universally relatable travel emotions (wanderlust, culture shock, homecoming feeling).
- Never force a cultural reference — only include if it fits naturally.

CAPTION STRUCTURE REQUIREMENTS:
1. LINE 1 (Hook): 80-150 characters MAX. This is what shows before "See More." Make it irresistible. No hashtags. No emojis in the first 10 words.
2. LINE 2 (blank line): Always leave one blank line after the hook.
3. BODY (3-6 lines): Deliver the value, story, or insight. Each line max 100 characters. Use line breaks for readability. Match {tone} voice.
4. EMOJI RULES: Use 2-5 emojis total. Place emojis at the END of a line, never mid-sentence. Use emojis that reinforce meaning, not decorate. For {target_region} Bangladesh: ✈️🌊🏔️🌿🍃🎒🗺️ work well for travel.
5. CTA LINE: One clear call-to-action. See CTA options below.
6. HASHTAGS: 15-20 hashtags on the final line. Mix of: 3 broad (1M+ posts), 7 niche (100K-1M posts), 5 hyper-local ({target_region}-specific), 2-3 pillar-specific. No spaces between hashtags.

CTA OPTIONS — select the one that fits {dominant_emotion}:
- Curiosity/Discovery: "Tag someone who NEEDS to see this 👇" or "Save this for your next trip 🗺️"
- Aspiration: "Drop a ❤️ if this is on your bucket list!" or "Which one are you visiting first? Comment below!"
- Urgency/FOMO: "This is disappearing — go before it's gone." or "Limited season — check the link now."
- Community: "Have you been here? Share your story in the comments!" or "Follow for more hidden gems like this 🌿"
- Educational: "Save this post — you'll need it later 📌" or "Share with someone planning a trip to {target_region}!"

LANGUAGE RULES FOR "{target_language}":
- If "English": Write entirely in English. Use simple, punchy sentences.
- If "Bangla": Write in standard Bangla (Unicode). Avoid overly formal register — use conversational Bangla that a 22-year-old would use on social media.
- If "Bilingual (English + Bangla)": Write the hook in English, then translate the core value line into Bangla immediately after (italic or bracketed). Use Bangla for the CTA. Hashtags in both English and Bangla transliteration.

CONSTRAINTS:
- Total caption (excluding hashtags): 150-400 characters is optimal for reach. Maximum 500 characters.
- Never use all-caps except for maximum ONE word for emphasis.
- Never use more than 3 exclamation marks in total.
- Never start with "I" as the first word.
- Never include external links in the caption body (Facebook suppresses reach).
- Avoid words flagged by Facebook: "free", "win", "giveaway", "click here", "buy now" — use alternatives.
- Must pass Facebook Community Standards: no misinformation, no clickbait that misleads.
